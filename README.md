# AutomatonWorks API

A simple JSON generated by scraping patch note announcements. 
Just ZZZ for now.
```
https://raw.githubusercontent.com/AutomatonWorks/API/refs/heads/main/zzz-calendar.json
```
It usually just updates once per patch, unless there's something wrong with it and we need to fix it. Hopefully we wont need to fix it, right? 

## Checking for updates

Compare `version` and `revision`:

- `version` is the game version (`"3.3"`). Compare it numerically, part by part (`3.10` is newer than `3.9`).
- `revision` starts at `1` for each version and goes up every time the content changes within that version (a fix, an event added late).

## Time zones

Each `start` and `end` comes in one of two forms:

- `{"utc": <unix seconds>}`: This is the same for everyone. MHY writes these in UTC+8 and we converts them to UTC.
- `{"server": "YYYY-MM-DDTHH:MM"}`: This is the **server time**, so it depends on region. If you forgot:

  | Region | Offset |
  |---|---|
  | America | UTC-5 |
  | Europe | UTC+1 |
  | Asia / TW, HK, MO | UTC+8 |

These offsets are fixed all year and the servers don't follow daylight saving, so uou'll have to do the conversion to your timezone and be aware of DST.

  `utc = server_time - offset_hours * 3600`. For example, `"2026-11-30T03:59"` on Europe is `2026-11-30T02:59Z`.
